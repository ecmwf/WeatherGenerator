Welcome to `WeatherGenerator-FastEvaluation`'s documentation!
===================================

**WeatherGenerator-FastEvaluation** is a modular evaluation and visualization package for verifying forecast
data and model outputs in the WeatherGenerator project. This package
reads the output of the inference stage from the WeatherGenerator and
provides statistics or exports to other tools.

.. include:: ../README.rst


Check out the :doc:`Documentation` section for further information, including how to use the config files to generate plots and scores.

.. note::

   This project is under active development.
