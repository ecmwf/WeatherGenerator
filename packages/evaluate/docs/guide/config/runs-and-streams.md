# default_streams, run_ids, and Stream Blocks

## default_streams

Defines stream configuration used by any `run_id` that does not specify its own `streams` block.

```yaml
default_streams:
  ERA5:
    regions: ["global"]
    channels: ["2t", "10u", "z_500", "t_850"]
    regrid: true
    evaluation:
      forecast_step: "all"
      sample: "all"
      ensemble: "all"
    plotting:
      sample: [0, 1]
      forecast_step: [1, 2, 4, 8]
      ensemble: [0]
      data_plots:
        - maps:
            predictions: [image, video]
            bias: [image]
        - histograms_per_sample
```

If a run defines `streams`, `default_streams` is ignored for that run.

## run_ids

Each key under `run_ids` is a run identifier.

### Common run keys

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `label` | str | yes | run_id | Label used in legends. |
| `color` | str | yes | auto | Matplotlib color for the run. |
| `type` | str | yes | `"zarr"` | One of `"zarr"`, `"json"`, `"merge"`, `"jsonmerge"`, `"csv"`. |
| `streams` | dict | yes | - | Stream config. If absent, `default_streams` is used. |

### Run type: zarr (default)

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `results_base_dir` | str | yes | private config | Base directory containing Zarr outputs. |
| `runplot_base_dir` | str | yes | `results_base_dir` | Base directory for map/hist outputs. |
| `metrics_base_dir` | str | yes | `results_base_dir` | Base directory for cached JSON score files. |
| `metrics_dir` | str | yes | `metrics_base_dir/evaluation` | Explicit score cache path. |
| `model_base_dir` | str | yes | - | Directory containing model config files. |
| `mini_epoch` | int | yes | `0` | Epoch number used to identify the Zarr store. |
| `rank` | int\|str\|list | yes | `"all"` | Rank(s) to read. |

### Run type: json

Reads pre-computed scores from JSON files (no Zarr required). Plotting maps/histograms/animations is not available.

### Run type: merge

Stacks multiple Zarr runs over ensemble dimension.

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `merge_run_ids` | list[str] | no | - | Existing run_ids to merge. |
| `merge_metrics_dir` | str | no | - | Output/cache directory for merged scores. |

### Run type: jsonmerge

Same as `merge`, but reads pre-computed JSON scores instead of Zarr data.

### Run type: csv

Reads pre-computed scores from CSV files generated by external tools.

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `metrics_dir` | str | no | - | Path containing `<run_id>/` CSV folder. |

For CSV schema, see [CSV format](csv-format.md).

## Stream config block

Same structure under `default_streams`, under `run_ids.<id>.streams`, and inside `merge` runs.

```yaml
ERA5:
  regions: ["global", "nhem"]
  channels: ["2t", "10u", "z_500"]
  offset: "1h"
  regrid: true
  climatology_path: "/path/..."
  evaluation:
    forecast_step: "all"
    sample: "all"
    ensemble: "all"
  plotting:
    forecast_step: [1, 2, 4, 8]
    sample: [0, 1]
    ensemble: [0]
    data_plots:
      - maps:
          predictions: [image, video]
          target: [image]
          bias: [image, video]
      - histograms_per_sample
      - timeseries
```

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `regions` | list[str] | yes | `["global"]` | Regions for 2D maps for this stream. |
| `channels` | list[str] | yes | all available | Channel names to process. |
| `offset` | str | yes | - | Timedelta offset used to infer init time when needed. |
| `regrid` | bool\|dict | yes | `false` | Re-project to regular lat/lon before scoring/plotting. |
| `climatology_path` | str | yes | auto | Explicit path for climatology Zarr needed by anomaly-based metrics. |

### evaluation sub-block

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `forecast_step` | str\|list[int] | yes | `"all"` | Forecast steps to score. |
| `sample` | str\|list[int] | yes | `"all"` | Samples to score. |
| `ensemble` | str\|list[int] | yes | `"all"` | Ensemble members to include. |

### plotting sub-block

| Key | Type | Optional | Default | Description |
|-----|------|----------|---------|-------------|
| `forecast_step` | str\|list[int] | yes | `"all"` | Forecast steps for plots. |
| `sample` | list[int] | yes | `"all"` | Samples for plots. |
| `ensemble` | str\|list[int] | yes | `"all"` | Ensemble members for plots. |
| `data_plots` | list | yes | `[]` | Data visualizations and output formats. |

#### data_plots entries

| Entry | Options | Produces |
|-------|---------|----------|
| `maps` | map kind -> formats (`predictions`, `target`, `bias`) | 2D scatter maps. |
| `histograms` | formats (default `[image]`) | Target vs prediction histograms. |
| `histograms_per_sample` | formats (default `[image]`) | One histogram per sample. |
| `histograms_across_samples` | formats (default `[image]`) | One histogram across samples. |
| `timeseries` | - | Prediction and target timeseries plots. |

### Regridding

When `regrid` is set, data is re-projected from native grid to regular lat/lon using [earthkit.regrid](https://earthkit-regrid.readthedocs.io/).

```yaml
ERA5:
  regrid: true
  # or
  regrid:
    target_grid: [1.5, 1.5]
    # target_grid: "O96"
    # original_grid: "O96"
```

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `target_grid` | [float, float] \| str | `[1.5, 1.5]` | Target grid. |
| `original_grid` | str | auto | Source grid name when auto-detect fails. |

Changing regrid settings does not automatically invalidate all cached JSON scores. See [Score Caching](score-caching.md).

### Climatology

A climatology is required for `acc`, `rps`, `rpss`, `fact`, and `tact`.

Auto-detection path:

```text
<data_path_aux>/climatology/<source_filename>_climatology.zarr
```

Limitations:

- Gridded data: climatology may be interpolated to model grid.
- Non-gridded/HEALPix data: climatology must already match point layout.
- Missing climatology file: affected metrics return `NaN`.
