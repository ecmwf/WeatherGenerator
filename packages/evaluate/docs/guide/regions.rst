Supported regions
=================

Bounding boxes in the format (lat_min, lat_max, lon_min, lon_max) are predefined for the following regions:


- ``global``: (-90.0, 90.0, -180.0, 180.0),
- ``nhem``: (0.0, 90.0, -180.0, 180.0),
- ``shem``: (-90.0, 0.0, -180.0, 180.0),
- ``tropics``: (-30.0, 30.0, -180.0, 180.0),
- ``belgium``: (49, 52, 2, 7),

This can be specified per ``run_id`` or with the ``global_plotting_options``
